# Global Antigravity Rules — Ailectra

You are working on **Ailectra**.

## Mandatory

- Use TypeScript.
- Use Next.js App Router.
- Use Prisma for database.
- Use Tailwind CSS and shadcn/ui.
- Use next-intl for EN/ID.
- Use next-themes with default dark.
- Use secure Auth.js setup.
- Use reusable components.
- Use Zod validation.
- Never expose secrets.

## UI

- Futuristic, modern, polished.
- Landing can be animated.
- Dashboard should be clean and fast.
- Every animated background must be inside `relative isolate overflow-hidden`.

## Security

Never bypass third-party AI login. Never steal cookies/session. Never store raw secrets.
