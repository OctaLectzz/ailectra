## Critical Requirements

- Next.js full-stack.
- TypeScript.
- Prisma + PostgreSQL.
- Tailwind CSS.
- shadcn/ui.
- Auth.js with Google OAuth and manual credentials.
- Dark/light mode, default dark.
- English/Indonesian i18n, default English.
- Multi-page landing.
- SEO and OG image.
- Lenis smooth scroll.
- Framer Motion / Motion.
- Three.js for selected hero/graph visuals.
- Aceternity UI, Magic UI, React Bits for landing effects.
- Reusable components.
- Secure credential handling.

## Security First

Do not implement illegal or unsafe auto-login. Use official OAuth/API/deep-link/manual secure flows only.
